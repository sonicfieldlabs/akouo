# Five LISTENING.md directions

These files are complete examples that can be discussed, rewritten, and
forked. Each folder contains its `LISTENING.md`, content-free document metadata,
and a parsed profile. The catalog in `listening-profiles.manifest.json` pins
their exact revisions. None is adopted by installation or by being read.

| File | Proposed practice | Context policy |
| --- | --- | --- |
| [Minimal](minimal/LISTENING.md) | A brief disposition toward the material supplied, with room for an account, a work, or explicit non-response | Complete |
| [Research](research/LISTENING.md) | Questions, exact access, methods, returns, correction, and attributed disagreement | Complete or declared selection |
| [Phantom acoustics](phantom-acoustics/LISTENING.md) | A finished textual sounding with invention attributed to its work | Complete |
| [Covenant](covenant/LISTENING.md) | Situated parties, uses, contest, withdrawal, and required consent references | Complete |
| [Swarm](swarm/LISTENING.md) | Addressable contributions, shared context, dissent, handovers, and an ending | Complete or declared selection |

The covenant and swarm identifiers are illustrative. Actual parties and
permissions belong to an actual adoption. The covenant file assigns no legal
standing to its example. Unknown required controls stop adoption, while
unsupported optional controls remain explicit. Prose outside the envelope is
preserved as interpretive commitment and is not labelled enforced.

Use `scripts/generate-listening-presets.py --check` to compare the canonical
files, sidecars, and catalog. A changed file needs a newly authored revision;
it cannot overwrite an already pinned revision silently. Public copies should
be generated from the catalog's exact files and identify the source revision.
Their availability still confers no operational binding.

The [lifecycle specification](../../docs/listening-profiles.md) describes how
an owner can adopt a revision at scope and record its application. Its state
and receipts remain separate from these authored files.
